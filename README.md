# Algorithm Atlas

机器学习与深度学习算法知识库，支持中文、英文、法语三语切换，以及算法搜索、筛选、对比、学习路径和核心术语浏览。

## Features

- 56 个主流机器学习与深度学习算法条目
- 中文 / English / Francais 三语展示
- 算法搜索、方向筛选、难度筛选和排序
- 算法详情弹窗、最多 3 项对比和一键清除对比
- 学习路径、知识图谱和术语卡片
- 纯静态网站，可直接部署到 GitHub Pages、Netlify、Vercel 或任意静态托管服务
